# Magpie_Effects

给 [Magpie](https://github.com/Blinue/Magpie) 用的一些正经或娱乐的效果。

# 手动导入示例

1. 将 `xxx.hlsl` 复制到 Magpie 目录下的 `effects` 文件夹。
2. 重新启动 Magpie 即可自动扫描新导入的效果。
3. 在缩放模式的效果列表中添加 `xxx`，并按需要调整参数。

# 文件说明

## Crosshair

在画面中心绘制一个可配置的准心。

### 参数

| Param | 说明 |
| --- | --- |
| Red / Green / Blue | 准心的红、绿、蓝分量，均为 0 到 255 的整数。 |
| Opacity | 不透明度，0 到 255 的整数；0 为完全透明，255 为完全不透明。 |
| Size | 尺寸，单位为输出像素。十字和斜叉表示从中心到末端的长度；圆和圆环表示半径；方框表示半边长。 |
| Thickness | 线条粗细，单位为输出像素。实心圆不使用此项。 |
| Center Gap | 十字或斜叉中心留空的长度，单位为输出像素；其他形状不使用此项。 |
| Shape | 形状编号：0 十字、1 斜叉、2 实心圆、3 圆环、4 方框。 |
